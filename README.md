# quant-projects

A collection of independent quantitative finance research/engineering projects.
Each sub-folder is self-contained with its own README, dependencies, and tests.

## Projects

- [`prediction-market-mm/`](./prediction-market-mm/) — Market-making and
  microstructure research on prediction markets (Kalshi / Polymarket). See its
  README for scope, methodology, and current status.

## Repo conventions

- Each project lives in its own top-level folder.
- Each project folder has its own `README.md`, `requirements.txt`, `src/`, `tests/`,
  and `notebooks/`.
- Claims of results (Sharpe, accuracy, performance, etc.) are only made in a
  project's README once they are reproducible from the code in that folder.
